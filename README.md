# Бот оценок ЮУрГУ

Telegram-бот, который каждые 30 минут заходит в «ЮУрГУ-Онлайн» (online.susu.ru) и присылает вам новые баллы. Работает на серверах GitHub бесплатно и круглосуточно: компьютер включать не нужно.

Настройка занимает около 15 минут и делается в браузере. Программировать не нужно.

---

## Что умеет бот

**Сообщает о новых оценках:**

```
Новые оценки:

📘 История России — рейтинг по предмету 21,33%
🆕 Семинар 3: 4 из 5 (80%)
```

- 🆕 — новая оценка, ✏️ — преподаватель исправил баллы (`3 из 5 → 4 из 5`).
- В скобках — процент за эту работу.
- Рейтинг по предмету — как на online.susu.ru: процент от всех баллов семестра.

**Ведёт закреплённое сообщение** «📊 Рейтинг по предметам» с рейтингом по каждому предмету. Когда рейтинг меняется, бот редактирует это сообщение и не шлёт новое. Если закреп удалить, бот пришлёт и закрепит новый.

**Отвечает на `/start`** списком всех текущих оценок. Ответ приходит при ближайшей проверке, то есть в течение 30 минут.

Бот личный. Он показывает только ваши оценки, только вам, и отвечает только на ваш Telegram.

## Настройка

Понадобятся:
- аккаунт на [github.com](https://github.com) (бесплатный);
- Telegram;
- логин и пароль от online.susu.ru.

### Шаг 1. Создайте бота в Telegram

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя, например `Мои оценки`.
3. Придумайте username, он должен заканчиваться на `bot`, например `ivanov_grades_bot`.
4. BotFather пришлёт **токен**: длинную строку вида `123456789:AAH...`. Сохраните его, он понадобится на шаге 4.

> Токен — это пароль от бота. Никому его не показывайте.

5. Найдите своего бота по username и нажмите **Start**. Без этого бот не сможет вам писать.

### Шаг 2. Узнайте свой chat id

1. Откройте в Telegram [@userinfobot](https://t.me/userinfobot) и нажмите **Start**.
2. Он пришлёт ваш **Id**, число вида `123456789`. Сохраните его.

### Шаг 3. Скопируйте бота к себе на GitHub

1. Откройте страницу этого репозитория на GitHub.
2. Нажмите зелёную кнопку **Use this template → Create a new repository**.
3. Придумайте название, например `grades-bot`.
4. **Обязательно выберите Private.** В репозитории будут храниться ваши оценки, и посторонние не должны их видеть.
5. Нажмите **Create repository**.

> Не нажимайте **Fork**: копия-форк открытого репозитория будет открытой, и ваши оценки увидят все.

### Шаг 4. Добавьте секреты

Секреты — это закрытые настройки. GitHub передаёт их боту, но никому не показывает, даже вам.

1. В **своём** новом репозитории вверху нажмите **Settings**.
2. Слева выберите **Secrets and variables → Actions**.
3. На вкладке **Secrets** нажимайте **New repository secret** и добавляйте по одному:

| Name | Secret |
|---|---|
| `TELEGRAM_TOKEN` | токен от BotFather (шаг 1) |
| `TELEGRAM_CHAT_ID` | ваш Id (шаг 2) |
| `UNI_LOGIN` | логин от online.susu.ru |
| `UNI_PASSWORD` | пароль от online.susu.ru |

Имена пишите точно так же, большими буквами. Значения вставляйте без пробелов и кавычек.

4. Перейдите на вкладку **Variables** → **New repository variable**:
   - **Name:** `DEMO`
   - **Value:** `0`

### Шаг 5. Запустите

1. Вверху откройте вкладку **Actions**.
2. Если GitHub спросит, разрешить ли workflows, нажмите **I understand my workflows, go ahead and enable them**.
3. Слева выберите **«Проверка оценок»** → справа **Run workflow** → **Run workflow**.
4. Через минуту в Telegram придёт «Начал следить за оценками» со списком оценок, а рядом закреплённое сообщение с рейтингом.

Готово. Дальше бот работает сам.

## Если что-то не так

**После запуска ничего не пришло.**
Откройте **Actions** и посмотрите на последний запуск.
- ❌ **Красный крестик.** Нажмите на запуск → **check** → строку с ошибкой. Если там `Не заданы TELEGRAM_TOKEN и TELEGRAM_CHAT_ID`, проверьте имена секретов. Если `chat not found` или `Forbidden`, вы не нажали **Start** у своего бота (шаг 1, пункт 5) или ошиблись в chat id.
- ✅ **Зелёная галочка, но сообщения нет.** Проверьте, что ищете в чате со своим ботом, а не с BotFather.

**Пришло «⚠️ Не получилось проверить оценки».**
- Текст `неверный логин или пароль` — проверьте секреты `UNI_LOGIN` и `UNI_PASSWORD`.
- Другая ошибка — скорее всего, сайт вуза временно не работает. Бот пишет о каждой ошибке один раз, а когда всё наладится, пришлёт «✅ Проверка оценок снова работает».

**Сменили пароль от online.susu.ru.**
Settings → Secrets and variables → Actions → карандаш у `UNI_PASSWORD` → новый пароль → **Update secret**.

**Хочу приостановить бота.**
Actions → «Проверка оценок» → **⋯** справа вверху → **Disable workflow**. Включить обратно можно там же: **Enable workflow**.

**Хочу проверить, как это работает, без настоящих оценок.**
Поставьте переменную `DEMO` = `1`. Бот будет брать выдуманные оценки из `demo_grades.json`: отредактируйте этот файл на GitHub (карандаш → добавьте строку → **Commit changes**) и запустите проверку. Чтобы вернуться к настоящим оценкам, поставьте `DEMO` = `0`.

## Полезно знать

- **Бесплатный лимит.** В закрытом репозитории GitHub даёт 2000 минут в месяц, а проверки раз в 30 минут тратят около 1450. Поэтому чаще проверять не стоит.
- **Опоздания.** GitHub иногда запускает проверку на 5–15 минут позже расписания. Это нормально.
- **Неоценённые работы.** Работы с 0 баллов бот не показывает. Когда за такую работу поставят баллы, она придёт как новая (🆕).
- **Новый семестр** бот подхватит сам.
- **Коммиты «Обновить сохранённые оценки».** Их делает сам бот: так он запоминает, какие оценки уже присылал. Не удаляйте файл `state.json`, иначе бот пришлёт все оценки заново.

## Файлы

| Файл | Что делает |
|---|---|
| `.github/workflows/check-grades.yml` | расписание: запуск каждые 30 минут |
| `check.py` | одна проверка: сравнивает оценки, шлёт сообщения, обновляет закреп |
| `university.py` | вход в online.susu.ru и чтение баллов из журналов текущего семестра |
| `telegram.py` | отправка, редактирование и закрепление сообщений |
| `config.py` | настройки из секретов GitHub или файла `.env` |
| `get_chat_id.py` | показывает chat id (для запуска на компьютере) |
| `demo_grades.json` | выдуманные оценки для тестового режима |
| `state.json` | последние оценки; бот создаёт и обновляет его сам |

<details>
<summary>Запуск на своём компьютере (для разработчиков)</summary>

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env    # и заполните .env
.venv/bin/python check.py --print
```

С `--print` оценки выводятся в консоль: ничего не отправляется в Telegram и не сохраняется. Файл `.env` в `.gitignore` и на GitHub не попадёт.

Сайты ЮУрГУ могут не открываться через VPN. Если бот не может войти, выключите VPN.
